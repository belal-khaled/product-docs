# BlinkWebinars

BlinkWebinars is Envisioning's live and on-demand webinar platform. It allows users to register for scheduled sessions, watch live or replay streams, and hosts can embed players directly on external sites.

- [Getting Started](getting-started.md) — account setup and first steps
- [Registering for a Webinar](registering.md) — how to find and register for sessions
- [Watching a Webinar](watching.md) — live and replay viewing
- [Embedded Players](embedding.md) — embedding webinars on external pages
