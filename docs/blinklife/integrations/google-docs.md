# Google Docs

Connect Google Docs to reference and attach your Google documents directly inside BlinkLife notes and pages.

## Connecting Google Docs

1. Go to **Settings → Integrations**.
2. Click **Connect** next to Google Docs.
3. Sign in with your Google account and approve the permissions.

## Using Google Docs in BlinkLife

Once connected, you can link a Google Doc inside a BlinkLife Note or Page using the `/` command menu:
- Type `/google` or `/docs` and search for a document by name
- The linked doc appears as an embedded card with the document title and a link to open it

Sandra can also reference linked documents when you ask questions in Chat — for example, "Summarise the document I attached to the Q3 planning note."

## Permissions

BlinkLife reads document content to generate summaries on request. It does not edit or share Google Docs on your behalf.

## Disconnecting

Go to **Settings → Integrations** and click **Disconnect** next to Google Docs.
