Common issues and how to fix them.

## General tips

Before diving into a specific issue, try these first:

1. **Refresh the page** — most transient errors clear on reload.
2. **Sign out and back in** — clears stale session state.
3. **Check your internet connection** — Sandra requires an active connection for all responses.
4. **Try a different browser** — rules out browser-specific issues.
