# Listener Issues

## Microphone not activating

**Symptom:** Clicking the mic icon does nothing, or the browser asks for microphone permission repeatedly.

**Try:**
1. Check your browser's microphone permissions:
   - Chrome: address bar → padlock icon → Microphone → Allow
   - Safari: Preferences → Websites → Microphone → Allow for blinklife.com
2. Refresh the page after granting permission.
3. Ensure no other app (Zoom, Meet) is using the microphone exclusively.

## Transcription is inaccurate

Listener uses your device microphone and works best in quiet environments with clear speech. To improve accuracy:
- Speak at a steady pace and volume.
- Reduce background noise.
- Use a dedicated microphone or headset instead of a built-in laptop mic.

If a transcription is slightly wrong, you can edit the note after it is created.

## "Listen to my computer" not working

The **Listen to my computer** mode requires access to your system audio output, which requires additional browser permissions (or a system-level extension in some browsers). If it fails:
- Try in Chrome — it has the broadest audio capture support.
- Check that system audio is playing before activating Listener.
- Some operating systems block browser access to system audio entirely; in those cases, use the microphone-only mode.

## Listener stops mid-session

Listener sessions can time out after extended silence. If it stops unexpectedly:
- Click the mic icon again to restart.
- Check that the browser tab is not backgrounded aggressively (some browsers throttle background tabs).
