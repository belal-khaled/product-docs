# Password Reset

If you have forgotten your password, request a reset link from the login screen.

## How to reset your password

1. Go to [blinklife.com](https://www.blinklife.com) and enter your email address, then click **Continue**.
2. On the password screen, click **Forgot?**.
3. BlinkLife sends a reset link to your email address.
4. Click the link in the email and set a new password.

The reset link expires after a set period. If it has expired, request a new one by repeating the steps above.

## If you signed up with Google

Accounts created via Google SSO do not have a BlinkLife password. Sign in using **Sign in with Google** — you do not need a reset link.

## Still locked out?

If you no longer have access to the email address you signed up with, contact BlinkLife support from the login screen (**Need help?** link).
