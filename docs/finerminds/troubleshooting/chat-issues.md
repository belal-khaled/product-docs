# Chat Issues

## Messages not sending

1. Check your internet connection — chats require an active connection
2. Refresh the page and try again
3. If the conversation shows an error icon next to the message, click it to retry sending

## Not receiving messages

- Check that your browser notifications for finerminds.com are allowed:
    - Chrome: Settings → Privacy and security → Site settings → Notifications
    - Safari: Preferences → Websites → Notifications → Allow for finerminds.com
- Check that you haven't muted the conversation

## Conversation not loading

1. Hard-refresh the page (`Ctrl+Shift+R` on Windows/Linux, `Cmd+Shift+R` on Mac)
2. Clear your browser cache and reload
3. Try a different browser to rule out an extension conflict

## Community chat not visible

Community chats appear inside each network under the **Chat** tab. If you cannot see the tab, you may not yet be a member of that network — go to **All networks** and join first.

## Message shows as deleted

Messages that have been removed by their sender show as *"This message was deleted"*. This is expected behaviour and cannot be undone.
