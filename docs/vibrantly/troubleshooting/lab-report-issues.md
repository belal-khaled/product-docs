# Lab Report Issues

## Report is stuck in "Saved" and not being analyzed

Processing normally completes in under 60 seconds. If a report stays in **Saved** status after a few minutes:

1. Refresh the page and check the status again.
2. Try re-uploading the file — remove the stuck report and upload a fresh copy.
3. If the issue persists, the file format may not be fully supported. Try converting your report to a standard PDF and re-uploading.

## Biomarkers are missing or marked "Missing" in Body view

**Missing** means a biomarker was not found in your uploaded reports. Common causes:

| Cause | Fix |
|-------|-----|
| The test was not included in your panel | Upload a more comprehensive report, or accept that this marker is not in your data |
| Vibrantly could not extract the value from the format | Try re-uploading as a cleaner PDF or typed text file |
| The report used a non-standard marker name | Ask Luna in Chat — she can help identify the equivalent marker |

## Biomarker values look wrong

If an extracted value differs from what is on your lab report:

1. Open the original report and compare the specific value and unit.
2. Units matter — a value reported in µmol/L vs mg/dL will look very different as a number.
3. If the value is genuinely wrong, re-upload a cleaner file (e.g. a higher-resolution scan or a PDF instead of a photo).
4. You can also ask Luna in Chat: "My ferritin shows X but my report says Y — can you help me understand?"

## Duplicate reports appearing

If you uploaded the same report twice, the duplicate will appear as a separate entry. You can delete the extra copy from the Lab reports list without affecting your biomarker data (the analyzed data from the first upload is retained).

## Report upload fails

- Confirm the file is under the size limit (most PDFs are fine under 10 MB)
- Try a different browser or device
- If uploading a photo, ensure it is well-lit and the text is legible
